## 0. 前置（必须由主机完成；副机只等哨兵）

主机上要迁到副机的 4 个生图 tag：
  mbq_scalar, mllmq_t2i_text, mllmq_both, mllmq_gen_only

主机需要：
  1. 停掉这 4 个 tag 的 `eval_generate_quant.py` 进程（每个 lane 保留另一个 tag 继续跑）；
  2. 防止 local4 scheduler 因缺图重启 driver / lane queue（否则会把 4 个 tag 重新拉起来）；
     - 可临时停 local4 scheduler，或加 remote-owned 跳过规则；
  3. 确认主机上这 4 个 tag 无 `eval_generate_quant.py` 进程后，创建哨兵：
       touch /nas3/kangjia/mllmq/queue/REMOTE_GEN_GO

⚠️ 哨兵不存在时，副机 lane 只跑 W3A16 评分，不会启动生图。

## 1. 启动副机 4 条 lane

```bash
cd /nas3/kangjia/mllmq
mkdir -p output/logs/t2i_compbench_current

for pair in "mbq_scalar 0" "mllmq_t2i_text 1" "mllmq_both 2" "mllmq_gen_only 3"; do
  set -- $pair
  TAG=$1 GPU=$2 GATE_FILE=/nas3/kangjia/mllmq/queue/REMOTE_GEN_GO \
    setsid nohup bash queue/t2i_score_plus_gen_one.sh \
    > "output/logs/t2i_compbench_current/remote_lane_$1.log" 2>&1 < /dev/null &
  echo "launched $1 on GPU$2"
done
```

每条 lane 的行为：
  1. 立即在对应 GPU 上评 W3A16 的 8 个类别；
  2. 等 `queue/REMOTE_GEN_GO`；
  3. 哨兵出现后继续 W4A8 生图（skip-existing，从当前 PNG 数续跑）；
  4. 生图到 2400 后，同一张卡评 W4A8 的 8 个类别。
所有评分 skip-existing，可重复执行。

## 2. 检查

```bash
cd /nas3/kangjia/mllmq
for t in mbq_scalar mllmq_t2i_text mllmq_both mllmq_gen_only; do

  find "output/janus-pro-7b/t2i_compbench_current/w4a8/$t/t2i_compbench" -name '*.png' 2>/dev/null | wc -l
  echo -n "  w3score="
  ls "output/janus-pro-7b/t2i_compbench_current_scores/w3a16/$t"/*.json 2>/dev/null | wc -l
  echo -n "  w4score="
  ls "output/janus-pro-7b/t2i_compbench_current_scores/w4a8/$t"/*.json 2>/dev/null | wc -l
done

# 哨兵是否存在
ls -la /nas3/kangjia/mllmq/queue/REMOTE_GEN_GO 2>/dev/null || echo "NO GATE"

# 错误扫描
grep -RniE 'Traceback|CUDA out of memory|Killed|FAIL' \
  output/logs/t2i_compbench_current/remote_lane_*.log \
  output/logs/t2i_compbench_current/score_*.log 2>/dev/null | tail -20
```
